# Dokumentation

In diesen Ordner gehört alles, was erklärt, **wie** und **warum** ihr etwas gebaut habt. Für die IHK-Prüfung und für Arbeitgeber ist das oft genauso wichtig wie der Code.

| Datei | Inhalt |
|---|---|
| [anforderungen.md](anforderungen.md) | Was soll das Ergebnis können? Muss- und Kann-Kriterien |
| [entscheidungen.md](entscheidungen.md) | Wichtige Entscheidungen mit Begründung |
| [testprotokoll.md](testprotokoll.md) | Was wurde getestet, mit welchem Ergebnis? |
| `diagramme/` | UML-, ER- oder Netzwerkdiagramme (z. B. mit draw.io als `.drawio.png`) |
| `bilder/` | Screenshots für das README |

Tipp: draw.io-Dateien als **`.drawio.png`** speichern. Dann zeigt GitHub sie direkt als Bild an, und ihr könnt sie trotzdem in draw.io weiterbearbeiten.
