# Dokumentation – nach Phasen geordnet

Jedes Future-Lab-Projekt hat **dieselbe Struktur**, ähnlich wie die Projektarbeit in der IHK-Prüfung. Jede Phase hat ihren eigenen Ordner. So sieht man sofort, wo das Projekt steht – und die Projektdokumentation schreibt sich am Ende fast von selbst.

| Phase | Ordner | Was hinein gehört |
|---|---|---|
| **0 · Antrag** | [0-antrag/](0-antrag/) | Projektantrag, Checkliste für das Antrags-Review |
| **1 · Analyse** | [1-analyse/](1-analyse/) | Anforderungen (Lastenheft), Wirtschaftlichkeit |
| **2 · Entwurf** | [2-entwurf/](2-entwurf/) | Pflichtenheft, Entscheidungen, Diagramme |
| **3 · Umsetzung** | [`../src/`](../src/) | Code, Skripte, Konfiguration |
| **4 · Test und Abnahme** | [4-test-abnahme/](4-test-abnahme/) | Testprotokoll, Abnahmeprotokoll |
| **5 · Einführung** | [5-einfuehrung/](5-einfuehrung/) | Benutzeranleitung, Übergabe |
| **6 · Dokumentation** | [6-dokumentation/](6-dokumentation/) | Projektdokumentation, Zeitnachweis, Soll-Ist |
| **7 · Präsentation** | [7-praesentation/](7-praesentation/) | Folien, Probe-Prüfung |
| – | [bilder/](bilder/) | Screenshots für README und Anleitung |

**Goldene Regel:** Was nicht in GitHub ist, ist nicht passiert.

**Wichtig:** Stufe 1 ist ein Training für die IHK-Projektarbeit. Das echte Prüfungsprojekt entsteht im Praktikumsbetrieb.
