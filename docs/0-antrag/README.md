# Phase 0 · Antrag

Bevor gebaut wird, wird geplant. Jede Person schreibt einen Antrag für ihr Teilprojekt.

- `projektantrag.md` – Vorlage im IHK-Format. Im Team kopieren als `projektantrag-NAME.md`.
- `checkliste-projektantrag.md` – damit prüft ein anderes Team euren Antrag im Pull Request.

**Fertig, wenn:** Der Antrag ist per Pull Request geprüft und gemergt.
