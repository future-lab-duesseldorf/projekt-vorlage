# Projektstart – einmalig nach „Use this template“

Diese Schritte macht **eine Person aus dem Team** direkt nach dem Anlegen des Repositorys. Dauer: ca. 15 Minuten.

## 1 · Meilensteine anlegen (= die Phasen)

Auf GitHub: **Issues → Milestones → New milestone**. Diese acht Meilensteine anlegen, genau so benannt:

| Meilenstein | Beschreibung |
|---|---|
| `0 · Antrag` | Projektantrag geschrieben und geprüft |
| `1 · Analyse` | Anforderungen und Wirtschaftlichkeit |
| `2 · Entwurf` | Pflichtenheft, Entscheidungen, Diagramme |
| `3 · Umsetzung` | Code bzw. Konfiguration |
| `4 · Test und Abnahme` | Tests und Abnahme durch den Auftraggeber |
| `5 · Einführung` | Übergabe und Benutzeranleitung |
| `6 · Dokumentation` | Projektdokumentation und Soll-Ist |
| `7 · Präsentation` | Probe-Prüfung |

Wer mag, trägt bei jedem Meilenstein ein Zieldatum ein.

## 2 · Projekt-Board anlegen (= der Zeitplan)

**Projects → Link a project → New project → Board**. Spalten: **Offen · In Arbeit · Fertig**. Dann im Repository unter **Projects** das Board verknüpfen.

## 3 · Team einladen

**Settings → Collaborators and teams** – oder das passende Team der Organisation hinzufügen.

## 4 · README ausfüllen

Projektname, Ein-Satz-Beschreibung, Team, Fachrichtung. Den Rest füllt ihr nach und nach.

## 5 · Los geht's mit Phase 0

Jede Person schreibt ihren Antrag in `docs/0-antrag/` – Anleitung im Handbuch: [IHK-Projekt üben](https://cuboid-mulberry-747.notion.site/IHK-Projekt-ben-Selbststudium-405b5fb9a09381b1978cc05dfdc229cd).
